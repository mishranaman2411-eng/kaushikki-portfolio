# Naman Mishra — Creative Web Designer Portfolio

> Personal portfolio website for **Naman Mishra** (creative web designer, founder of **Weerolliinn**, CTO at **ARAEL WEARS**, and 3rd-year B.Tech ECE student at **CCET Chandigarh**). Built with Vite, React, Tailwind CSS, Lenis smooth scroll, and GSAP.

---

## 🎨 Design System

- **Warm Paper Canvas:** `#F8F7F4` dot-grid background with crisp ink-black typography (`#121212`).
- **Fonts:** *Plus Jakarta Sans*, *Newsreader*, *Caveat*, *Kalam*, and *JetBrains Mono*.
- **Tactile Details:** Washi tape accents, paperclips, a flippable Polaroid ID card, hand-drawn ink SVG doodles, and a scroll-drawn terracotta path.

---

## 🚀 Sections

1. **Top Navigation:** Monogram badge `NM`, section links (`About`, `My Works`, `Education`, `Contact`), live Chandigarh clock, and **View GitHub** link.
2. **Hero:** Headline (`"Creative websites that make your brand look trusted."`), three highlight cards (`Interactive`, `CTO`, `Modern Web`), action buttons, and a clickable flip card.
3. **Studio Memo (Apple Notes):** Ruled single-column note about good design, fast loading, smooth interactions, and an interactive skills checklist.
4. **My Works:**
   - **Weerolliinn (Founder & Owner):** Creative dark designs, custom fonts, smooth scroll animations, and an interactive product page with a 2-step order and receipt screen.
   - **ARAEL WEARS (Chief Technical Officer):** Streetwear online store with product pop-ups, a phone-friendly lookbook, and retro PlayStation-style intro animations.
   - **My Portfolio Website:** This site, featuring a flip card, editorial look, and an email-drafting contact section.
5. **Education & Journey:** Winding scroll-drawn path covering Satluj Public School (2022), GMSSS-37 Chandigarh (2024), CCET Chandigarh B.Tech ECE (2024–2028), and Self-Made Web Designer skills (HTML, CSS, JavaScript, TypeScript, React, Next.js, GSAP, Three.js).
6. **Contact:** Interactive iOS-style mail composer with topic pills (`Creative Website`, `Online Store`, `Website Redesign`, `Internship / Collaboration`) and one-click copy buttons for Email, Phone/WhatsApp, and GitHub.
